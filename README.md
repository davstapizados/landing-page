# Landing Oficial Davs Tapizados

Landing page oficial de **Davs Tapizados**, creada para presentar el Programa de Puntos de Atención y captar negocios interesados en incorporar el servicio de tapizados automotrices.

## Objetivo

La landing está orientada a propietarios de talleres, lubricentros, lavaderos, gomerías y otros negocios del sector automotriz.

Su función es explicar:

- qué es un Punto de Atención;
- cómo funciona el programa;
- qué beneficios recibe el negocio;
- cómo contactar a Davs Tapizados.

## Sitio publicado

https://davstapizados.com

## Tecnologías utilizadas

- HTML5
- CSS3
- Cloudflare Pages
- GitHub
- Google Fonts alojadas localmente
